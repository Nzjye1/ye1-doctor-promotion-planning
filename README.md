# Ye1 医生晋升与科研规划

**结合岗位条件和已有基础，统筹医生晋升、课题、文章与研究工作。**

面向支持 Skill 指引的各类 AI Agent，用自然语言交办任务。

## 能做什么

- 结合地区、医院、岗位和目标职称，核对晋升条件与申报材料。
- 梳理已有临床工作、科研成果和个人贡献，按要求准备工作总结。
- 将考试或考核、课题、论文和单位内部节点放进同一份计划。
- 查找近期适合的课题机会，结合医生研究基础推进申报准备。
- 根据已有数据、文章或在投稿件，衔接研究设计和投稿工作。
- 同时考虑临床、基础和转化研究，遇到困难时寻找可执行的下一步。

## 安装到你的 Agent

将下面这段话发给你的 Agent：

> 请从 https://github.com/Nzjye1/ye1-doctor-promotion-planning 获取 Ye1 医生晋升与科研规划。读取 `skills/ye1-doctor-promotion-planning/SKILL.md`，按照当前 Agent 支持的方式安装完整 Skill 文件夹并检查所需工具，然后告诉我如何开始使用。

也可以下载 [通用 Skill 包](downloads/ye1-doctor-promotion-planning-skill.zip)，解压后将完整文件夹导入或放入所用 Agent 的技能目录；WorkBuddy 用户可使用 [WorkBuddy 导入包](downloads/ye1-doctor-promotion-planning-workbuddy.zip)。

根据任务使用当前 Agent 可用的检索、文件和文档工具。

## 开始使用

你可以从当前最需要的环节开始，把下面适合你的一段话发给 Agent。

### 1. 从晋升目标开始

> 我准备晋升副主任医师，请结合我的地区、医院、岗位和现有成果，帮我梳理晋升要求，告诉我现在最该先做什么。

### 2. 核对已有材料

> 这是医院的晋升文件和我目前的成果清单，请逐项对照要求，整理已经具备的条件和接下来需要准备的材料。

### 3. 规划论文工作

> 我手头有一篇在写的文章和一篇在投文章，请结合晋升目标，帮我安排选刊投稿、进度跟进和后续论文工作。

### 4. 寻找近期课题机会

> 请结合我的科室、研究方向和已有基础，查找近期适合申请的课题，核对项目条件、申报截止和医院内部节点。

### 5. 还没有现成研究方向

> 我想为晋升准备文章和课题，但目前没有明确方向，请根据我的临床工作或实验基础，帮我寻找可开展的研究并制定下一步计划。

### 6. 把考试纳入安排

> 请帮我核对目标职称可能需要的考试或考核，整理报名、考试、成绩使用和医院相关时间节点。

### 7. 准备工作总结

> 请根据我任现职以来的临床工作、教学和科研资料，按晋升文件要求整理一份可编辑的工作总结草稿。

### 8. 同时规划临床与基础研究

> 我既做临床工作也参与基础研究，请帮我把现有工作、课题和论文一起纳入晋升计划，并对照岗位要求核对成果如何使用。
